шаг 1 — создать базу данных
  1. Откройте console.firebase.google.com
  2. Нажмите «Create a project» → придумайте имя → создайте
  3. Слева выберите «Build → Realtime Database»
  4. Нажмите «Create Database» → выберите регион → «Start in test mode»
  5. Перейдите в «Project settings» (шестерёнка) → внизу нажмите «Add app» → Web (</>)
  6. Придумайте имя приложения → нажмите «Register app»
  7. Скопируйте блок firebaseConfig = { ... } — вставьте ниже
шаг 2 — вставьте конфиг
Вставьте JSON-объект конфига. Можно скопировать прямо из Firebase — подойдёт и формат const config = {...}, мы сами достанем JSON.
Не удалось прочитать конфиг. Проверьте формат.
